# onimeku-data

Cermin data statis proyek **Onimeku** (baru), disajikan ke seluruh dunia
lewat CDN jsDelivr. Sumber kebenaran tetap API + database Onimeku;
repo ini adalah salinan bacaan-cepat yang diperbarui oleh sinkron.

## Alamat berkas (pola resmi jsDelivr untuk GitHub)

- Katalog: https://cdn.jsdelivr.net/gh/adiytharpansa/onimeku-data@main/catalog.json
- Detail judul: https://cdn.jsdelivr.net/gh/adiytharpansa/onimeku-data@main/titles/<id-anime>.json
- Subtitle (menyusul): subs/<id-anime>/<episode>.<bahasa>.vtt

## Catatan

- Berkas di cabang (branch) tersimpan di cache CDN dan diperbarui
  berkala; untuk yang paling segar, API Onimeku tetap rujukan utama.
- Semua data di sini adalah data publik katalog (judul, poster,
  episode) — tidak ada kunci atau data pengguna.
